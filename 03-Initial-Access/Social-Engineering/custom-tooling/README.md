# 🛠️ Custom Tooling

Central de scripts, automações e ferramentas internas do ecossistema. Este repositório/módulo contém utilitários para acelerar o desenvolvimento, linting, pipelines de CI/CD e geração de código.

---

## 🚀 Ferramentas Disponíveis

| Ferramenta | Comando | Descrição |
| :--- | :--- | :--- |
| **Code Generator** | `pnpm tool:gen` | Gera boilerplate de novos componentes/módulos |
| **Lint & Fix All** | `pnpm tool:lint` | Roda formatadores e linter customizados |
| **Deploy Helper** | `pnpm tool:deploy` | Script interativo para deploys em staging/prod |

---

## 🛠️ Requisitos Préveis

- **Node.js**: `>=18.x`
- **Package Manager**: `pnpm` (ou `npm`/`yarn`)
- **CLI Auxiliar**: Docker (se aplicável)

---

## ⚡ Como Usar

### 1. Instalação
```bash
pnpm install
``
